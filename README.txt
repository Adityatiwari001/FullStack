Student Management System - Fixed React (simple CSS)
------------------------------------------------------------------
How to run:
1. Install Node.js
2. Open this folder in terminal
3. Run:
   npm install
   npm run serve-json
   npm start
4. Open http://localhost:3000
Login: admin / admin

Notes:
 - JSON Server runs on port 3001 and provides /students endpoint
 - If fetch fails, ensure JSON Server terminal is running (do not close)
 - The original project guide is included in this folder:
   /mnt/data/Guide - Student Result Management System.pdf
